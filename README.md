# DATA ANALYTICS PROJECT : CUSTOMER AND PRODUCT INSIGHTS

## 📌 PROJECT OVERVIEW
  This is a data analytics project. It analyzes customer,product, and sales data to uncover insights that suppor better business decisions. The data set comes form my data warehousing project, which used medallion approach to build clean, structrued data model.


## 🎯 Objectives
  - Explore and understand the structue, type and quality of the dataset gained in the warehousing project
  - Measure sales performace across customers,product, and time.
  - Identify trends, segments, top performers, and underperformers to better understand the business environment
  - Deliver reports that support business decision-making


## 📂 Dataset
The dataset is focused on theree main ateas
 - Dim_customers : This focuses on details of all customers associated with our business.
    This dataset cointains crucial information such as customer_id, customer_key, customer_name, country, gender, birthdate, create_date etc.
   
 - Dim_products : This focuses on details about all the products offered by our business.
    This dataset cointains crucial information about our products such as product_key, product_id, product_name, category_id, category_name, subcategory, cost,
    maintainence, startdate etc.

 - fact_sales : This dataset focuses on detail information about all the orders and sales informations.
     This dataset cointains crucial infomation about order_number, customer_id, product_key, order ship and due dates, sales_amount, qunatity, and price



## 🔍 What's included
  ### 1. Exploratory Data Analysis (EDA)
  - Database exploration
  - Dimension Exploration
  - Date exploration
  - Measure exploration
  - Magnitude analysis
  - Ranking analysis

 ### 2. Advnance Analytics
 - Change-over-time analysis (trends and seasonality)
 - Cumulative analysis (running totals, moving averages)
 - Performance analysis (year_over_year analysis)
 - Part to whole analysis (category contribution to total sales)
 - Data segmentation (segmenting customers and products based on sales)

### 3. Final reports
  - Customer Report
  - Product Report



## 📈 How This Supports Decision-Making
- **Product positioning**: shows which products and categories perform best, so you know what to promote or rethink
- **Customer targeting**: segmentation helps focus marketing on high-value groups
- **Sales planning**: trend and seasonality analysis supports forecasting and inventory decisions
- **Performance tracking**: year-over-year and cumulative views show whether the business is growing
